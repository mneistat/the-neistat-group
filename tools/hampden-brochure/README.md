# Hampden board brochure

Four US Letter pages. Redesigned September 21, 2026. Fonts and original assets are bundled for faithful reproduction.

From the repository root:

```sh
pip install -r tools/hampden-brochure/requirements.txt
python3 tools/hampden-brochure/generate_brochure.py --output hampden-board-site/Hampden-Board-Brochure.pdf
```

The five-item checklist, five options, commission terms, and key qualifications are retained. Detailed lending timelines and unverified operating figures are covered in the linked online background. This design pass does not newly verify underlying property, legal, or lending claims. Review rendered pages after edits.
